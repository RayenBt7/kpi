# AAF KPI ML

Couche Machine Learning séparée du backend Node/Express.

## Objectif V1
- nettoyer et normaliser les données
- lire SQL Server
- produire un premier smoke test nightly
- préparer KPI Risk, Anomaly Detect et Action Suggest

## Commande de démarrage
python -m ml.run_nightly

## Dépendances
- Python 3.13
- SQL Server
- ODBC Driver 17 ou 18 for SQL Server
